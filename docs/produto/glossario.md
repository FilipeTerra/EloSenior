# Glossário do Domínio

Termos usados nas specs, na interface e no código. Em caso de dúvida, este glossário vale.

| Termo | Definição |
|---|---|
| **Família** | Grupo de pessoas que cuida em conjunto de um ou mais idosos. É a unidade de isolamento de dados: nada é visível fora da família. |
| **Idoso** | Pessoa cuidada. Tem perfil na família, mas não tem login no MVP. Uma família tem de 1 a 5 idosos. |
| **Membro (da família)** | Usuário com conta que participa de uma família, com um **Papel**. Não confundir com o papel "Membro". |
| **Papel** | Nível de permissão: **Admin** (gerencia membros e a família), **Membro** (cria e edita conteúdo), **Leitor** (só visualiza). |
| **Convite** | Link de uso único, com validade, que dá a uma pessoa acesso à família com um papel pré-definido. |
| **Médico** | Profissional de saúde cadastrado na família (nome, especialidade, contatos). Pertence à família e pode atender vários idosos. |
| **Condição** | Diagnóstico ou problema de saúde de um idoso (ex.: hipertensão), com status (ativa, controlada, resolvida). |
| **Alergia** | Substância que causa reação ao idoso, com gravidade. |
| **Medicamento** | Remédio em uso (ou já usado) por um idoso, com dose, posologia e período. |
| **Posologia** | Regra de quando tomar o medicamento: horários fixos, intervalo, dias da semana, ou "se necessário". |
| **Dose** | Uma ocorrência agendada de um medicamento em data e hora específicas. Tem status: pendente, tomada, pulada ou perdida. |
| **Receita** | Prescrição médica guardada como documento, com data de emissão, validade e medicamentos associados. |
| **Documento** | Arquivo (foto ou PDF) guardado no app: exame, laudo, receita, atestado, plano de saúde, identidade etc. |
| **Compromisso** | Evento na agenda de um idoso: consulta, exame, procedimento ou outro. |
| **Acompanhante** | Membro que vai com o idoso a um compromisso, ou é responsável por ele. |
| **Lembrete** | Notificação programada para compromisso, dose, receita a vencer ou tarefa. |
| **Escalonamento** | Aviso extra a outros membros quando uma dose importante não é confirmada a tempo. |
| **Despesa** | Gasto realizado com o cuidado, com valor, data, categoria, idoso e quem pagou. |
| **Pagador** | Membro (ou o próprio idoso, ou outra pessoa) que pagou a despesa. O MVP só registra, não divide. |
| **Tarefa** | Algo a fazer para o cuidado (ex.: buscar remédio), com responsável e prazo. |
| **Registro do dia** | Anotação livre de um membro sobre como o idoso passou o dia. |
| **Atividade (feed)** | Evento automático registrado quando alguém cria, altera, exclui ou confirma algo. Aparece no feed da família. |
| **Ficha de emergência** | Resumo de uma tela com os dados essenciais do idoso para uso em urgência. |
| **Arquivar** | Encerrar o acompanhamento de um idoso mantendo os dados em modo somente leitura. |
| **Lixeira** | Local onde itens excluídos ficam por 30 dias antes da remoção definitiva. |
